# ADS Research

> 这个目录用于沉淀 ADS 对外部 Agent Harness 生态的持续研究，而不是一次性分析。

## 为什么需要 research 层

如果 ADS 只迭代自己，很容易陷入“内部视角正确，但外部世界已经变了”。  
研究层的作用是：

- 追踪外部 harness 生态的真实分层
- 发现值得吸收的协议、工作流、产品形态
- 识别 ADS 当前仍未覆盖的空白
- 为 roadmap 提供证据，而不是只靠直觉

## 推��节奏

### 日常

- 收集新工具、新协议、新文章、新案例
- 记录原始来源与最小判断

### 周度

- 归并为 `findings.md`
- 明确“新信号”和“旧判断是否变化”

### 月度

- 输出一份 landscape report
- 给 ADS roadmap 回写优先级调整

## 研究输出的最低要求

- 不只列链接，要写关键判断
- 不只讲趋势，要写对 ADS 的具体影响
- 不只说“值得关注”，要给出是否纳入 roadmap 的结论
